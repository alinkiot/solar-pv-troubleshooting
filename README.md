# 光伏电站运维故障诊断

面向光伏电站运维的 WorkBuddy Skill，帮助分析发电异常、设备告警、逆变器停机、组串输出异常、热斑和组件缺陷，并整理有依据、分步骤的排查建议。

## 功能

- 按安全风险、影响范围和现场证据组织故障排查。
- 汇总发电量影响因素及逆变器、交流/直流回路、组件等常见故障线索。
- 区分已确认现象与待验证原因，生成排查和故障记录模板。
- 附带培训资料截图裁出的示例图片。

## 安装到 WorkBuddy

在 WorkBuddy 对话中直接发送下面这句话：

> 帮我安装这个 SKILL：https://github.com/alinkiot/solar-pv-troubleshooting.git

如果 WorkBuddy 提示确认安装，按界面提示完成即可。
```

如果 WorkBuddy 当前版本不支持直接从 Git 安装，可先克隆仓库，再将克隆下来的技能文件夹导入 WorkBuddy：

```bash
git clone git@github.com:alinkiot/solar-pv-troubleshooting.git
```

## 文件说明

- `SKILL.md`：技能触发条件、诊断流程、安全边界和报告模板。
- `references/故障知识库.md`：典型故障、环境因素及诊断参考。
- `assets/`：故障、遮挡和热斑示例图片。

## 使用与安全提示

启用后，在 WorkBuddy 中描述设备、告警原文、发生时间、影响范围及同期对照数据，即可请求辅助分析。请勿将常见原因当作确定结论。

本 Skill 仅提供辅助诊断，不替代现场规程、调度指令、设备手册或专业人员判断。带电检查、停送电、验电接地和保护操作必须由有资质人员按适用规程执行；遇到触电、拉弧、冒烟或火情等风险时，应停止远程试错并按现场应急预案处置。示例图片及截图中的参数仅供参考，须以现行标准和设备文件为准。
